# Navegador 4.0

Navegador Android nativo em Kotlin, com interface própria e Chromium/Blink pelo Android System WebView.

A primeira versão está em desenvolvimento. O motor é fornecido e atualizado pelo Android System WebView; este repositório não é um fork completo do código-fonte do Chromium e não inclui os serviços do Google Chrome.

## Primeira entrega

Barra inferior, abas, favoritos, histórico, downloads, compartilhamento, tela cheia, seletor de arquivos, permissões por site e restauração de sessão. Recursos de inteligência e pesquisa serão desenvolvidos em etapas posteriores.
